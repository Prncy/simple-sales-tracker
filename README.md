# Stock & Sales Tracker

A mobile-first web application for recording product sales and returned goods, managing product details, and exporting monthly reports.

## Project status

Initial project setup is in progress. The first implementation stage establishes the frontend foundation and Supabase database plan.

## Planned stack

- React + TypeScript + Vite
- Supabase Auth and PostgreSQL with Row Level Security
- Responsive CSS
- TXT and DOCX monthly report exports

## MVP scope

- Employee sign-up and sign-in
- Create and manage businesses and products
- Record sales with the sale-time unit price saved on each transaction
- Record returned goods separately from sales
- Monthly reporting by product and employee
- Copy report text or export TXT/DOCX

The application will not claim to calculate accurate stock on hand because opening stock and stock received may be unknown.

## Currency

The initial UI uses Zambian kwacha (ZMW) as a provisional display currency.
